Automatic migration of the 2.0.0 data, and a driver copy that holds up with large packages (Canon's, for one).

> The application's interface is in Italian.

### Added

- **Automatic migration from 2.0.0.** On first start, settings, task queue, log and driver cache are moved from `%LOCALAPPDATA%\Duck\PrinterManager` to `%APPDATA%\duck\DuckPrinter`; queued tasks keep finding their drivers. It works even if 2.0.1 has already been started. The theme keeps the choice made before. Nothing to move by hand.

### Fixed

- **Drivers with many files (Canon's, for one) failing while being copied.** A driver travels as a single zip and is unpacked on the PC into a short, accessible temporary folder, `C:\Windows\Temp\DuckPM\<8 characters>`: no more paths over 260 characters, no read-only files, a single transfer over WinRM too. When a file cannot be unpacked, the error names it and says how long its path is.
- **The temporary folder is always removed** when the operation ends, successful or not; folders left by interrupted attempts are removed after a day, and only the ones the app created.
- The old default working folder (`C:\ProgramData\DuckPM`) switches to the new one on its own.
- **Scheduled tasks:** the task list fills its panel to the bottom; the space for the selection bar is kept only while the bar is shown.
