Signed drivers that need their publisher to be trusted now install over the network too.

> The application's interface is in Italian.

### Fixed

- **Signed drivers that would not install on some PCs (HP Universal Printing, for one).** `pnputil` stopped with `0xE0000242`: the driver's publisher was not yet trusted on that PC, and over WinRM nobody can answer Windows' *"Always trust software from HP?"*. Before installing, the app now adds the signer of the driver's catalogue to the PC's **Trusted Publishers** — only for valid signatures, which is what clicking *Install* does. On by default; **Impostazioni › Deploy** turns it off.
- **`pnputil` exit codes are translated in the task log**: publisher not trusted, root not trusted, unsigned driver, catalogue not matching the files, reboot required.
- **No more "temporary folder not removed" for an account that was refused**: the folder was never created.
