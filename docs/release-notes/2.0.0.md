The first release of version 2: `start.ps1` rewritten as a .NET 8 application, with PowerShell for the commands on the PCs and a Rust core for the task queue.

> The interface is in Italian. On first start open **Impostazioni**: the values it ships with are examples (`example.local`, `OU=Printers,...`).

### Highlights

- **Deploy as a wizard** — operation, computers, driver (read with SetupAPI), printer, summary, done. Remove-before-install asked in the summary; starting values in **Impostazioni → Procedura**.
- **A task per PC, in order** — PCs that are off are pinged every 10 minutes with no expiry; a removal followed by an install never runs the other way round.
- **Two accounts tried in turn** — the AD account you signed in with and your Windows account, with a clear message when both get *access denied*.
- **MAC Auth** — search by MAC or host name, edit in place (new MAC = new password), new-account wizard, delete from the card.
- **Light and dark theme**, optional glass with Windows' blur, illustrated sidebar, duck avatars.

Full list in [CHANGELOG.md](https://github.com/Zaick99/DuckPrinterManager/blob/main/CHANGELOG.md).
